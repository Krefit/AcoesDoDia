# AcoesDoDia

AcoesDoDia é um projeto voltado para análise e backtesting de ações, utilizando bibliotecas como `stock_analysis` e `pandas`. O objetivo é auxiliar na tomada de decisão para investimentos com base em estratégias quantitativas.

## Recursos

- Coleta e análise de dados de ações.
- Implementação de backtesting para testar estratégias de investimento.
- Integração com `stock_analysis` para facilitar a análise de ativos financeiros.

## Estrutura do Projeto

- `main.py` - Arquivo principal para execução do código.
- `backtrading.py` - Implementação de backtesting de estratégias.
- `stock_analysis.py` - Módulo para coleta e análise de dados de ações.
- `stocks_db.py` - Gerenciamento e armazenamento de dados de ações.

## Instalação

1. Clone este repositório:
   ```sh
   git clone https://github.com/Krefit/AcoesDoDia.git
   ```
2. Instale as dependências necessárias:
   ```sh
   pip install -r requirements.txt
   ```

## Como Usar

1. Configure os parâmetros desejados nos arquivos de estratégia.
2. Execute `main.py` para rodar a análise e backtesting:
   ```sh
   python main.py
   ```
